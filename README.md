# coil-sdg13-gallery

Spletna galerija o cilju trajnostnega razvoja **SDG 13 – Podnebni ukrepi** (projekt COIL).

Objavljena stran: https://UPORABNISKO-IME.github.io/coil-sdg13-gallery/

## Razdelitev dela

- **Student A:** SDG introduction, photography (6 photos), homepage design, intro video.
- **Student B:** problem research, photography (6 photos), second part of gallery and conclusion, intro video.
- **Together:** interactive quiz and survey, gallery development, testing and publication.

## Struktura

- `index.html` – struktura in vsebina
- `style.css` – oblikovanje
- `script.js` – galerija s filtri, kviz, anketa
- `images/dijakA`, `images/dijakB` – fotografije
- `videos/` – videoposnetki (večje objavita na YouTube kot Unlisted)

## Viri

- Vpišita uporabljene vire (Združeni narodi, ARSO, IPCC ...).
